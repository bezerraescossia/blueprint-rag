# Shared Data Model: RAG System

**Epic**: .spec/E1-rag-system/epic.md

Entities defined here are binding for every feature under this epic — a feature's own `data-model.md` (generated by `sdd-plan`) must reference these, not redefine them.

## Document

**Represents**: A single source document ingested into the template (a PDF, markdown file, web page, etc.) before chunking.
**Used by**: F1, F6

| Field | Type | Notes |
|---|---|---|
| document_id | string | Stable unique identifier, referenced by Chunk and by eval examples for provenance |
| source_uri | string | Where the raw document came from (file path, URL) |
| content_hash | string | Hash of raw content, used to detect re-ingestion and for DVC versioning correlation |
| metadata | object | Free-form (title, author, ingestion timestamp, etc.) — kept generic per the template's non-domain-specific scope |

**Relationships**: One `Document` produces many `Chunk`s.

## Chunk

**Represents**: A retrievable unit of text produced by splitting a Document, the atomic thing that gets embedded and indexed.
**Used by**: F1, F3, F6

| Field | Type | Notes |
|---|---|---|
| chunk_id | string | Stable unique identifier |
| document_id | string | Foreign key to `Document` |
| text | string | The chunk's raw text content |
| position | integer | Order of this chunk within its source document |
| embedding_ref | string | Reference/ID into the vector index for this chunk's `Embedding` (not the vector itself) |

**Relationships**: Belongs to one `Document`; has exactly one `Embedding`; appears as a `RetrievedChunk` when returned by retrieval.

## Embedding

**Represents**: The vector representation of a Chunk, as produced by the embedding model and stored in the vector index.
**Used by**: F1, F3

| Field | Type | Notes |
|---|---|---|
| chunk_id | string | Foreign key to `Chunk` |
| vector | float[] | Dimensionality determined by the chosen embedding model (decided in F1's `sdd-plan`) |
| model_id | string | Which embedding model/version produced this vector — required for reproducibility (Constitution Principle II) |

**Relationships**: Belongs to exactly one `Chunk`.

## Query

**Represents**: An incoming natural-language question from a user or evaluation example.
**Used by**: F3, F4, F5, F6, F8

| Field | Type | Notes |
|---|---|---|
| query_id | string | Unique per request, used to correlate logs/traces (Constitution Principle V) |
| text | string | The raw question text |
| timestamp | string | When the query was received |

**Relationships**: Produces a ranked list of `RetrievedChunk`s (via F3) and exactly one `Answer` (via F4).

## RetrievedChunk

**Represents**: A `Chunk` returned by the retrieval step for a specific `Query`, with its relevance score.
**Used by**: F3, F4, F6

| Field | Type | Notes |
|---|---|---|
| query_id | string | Foreign key to `Query` |
| chunk_id | string | Foreign key to `Chunk` |
| rank | integer | Position in the ranked result list |
| score | float | Similarity/relevance score from the retriever |

**Relationships**: Links one `Query` to one `Chunk`; the ordered set of these for a query is the input to F4's generation step and to F6's retrieval metrics (recall@k, MRR).

## Answer

**Represents**: The generated (or abstained) response to a Query.
**Used by**: F4, F5, F6, F8

| Field | Type | Notes |
|---|---|---|
| query_id | string | Foreign key to `Query` |
| text | string | Generated answer text, or an explicit abstention message (Constitution Principle IV) |
| abstained | boolean | True if the system declined to answer rather than risk hallucination |
| supporting_chunk_ids | string[] | Which `RetrievedChunk`s the answer is grounded in — needed for faithfulness evaluation in F6 |

**Relationships**: Belongs to one `Query`; references the `RetrievedChunk`s it was grounded in.

## EvalExample

**Represents**: A held-out labeled example used by the Evaluation Gate (Constitution Principle III) — not a live user query.
**Used by**: F6, F7

| Field | Type | Notes |
|---|---|---|
| example_id | string | Unique identifier |
| query_text | string | The evaluation question |
| expected_chunk_ids | string[] | Ground-truth relevant chunks, for recall@k / MRR |
| expected_answer | string | Reference answer, or expected-abstention flag, for generation metrics |

**Relationships**: Structurally mirrors `Query` + `Answer` but lives in the held-out eval set rather than production traffic; F7 logs metrics computed over collections of `EvalExample` runs.
